# Manual content

`content.json` is a curated, structured extract of the official Flydigi
Vader 4 Pro user manual PDF (`../vader4_pro_manual.pdf`). The PDF is
image-only (embedded 1240×1503 JPEGs at ~150 ppi); text was OCR’d and
cleaned for the companion UI.

Diagrams are lossless crops of those native embeds via `pdfimages` — no
upscaling, thresholding, or transparency hacks (those wreck line art).
UI shows them on a light “paper” card.

Always keep a link to the official online manual in the UI.
